# 熱蠟除毛學院・個人練習版

Hot Wax Academy — 熱蠟（硬蠟）除毛的互動課程，主教法是「順毛上蠟、逆毛取下」。

**打開就能用：** https://zank7.github.io/hot-wax-practice/

- 不用註冊、不用帳號密碼，手機、平板、電腦的瀏覽器都能開。
- 學習路徑 5 個階段、24 課：講義、互動教室、101 個子區的分區圖。
- 練習室：在分區圖上親手順毛上蠟、逆毛取下，系統記下一次做對的片數。
- 線上檢核：結業測驗 12 題、衛生「找出違規」、禁忌症篩檢。

## 進度存在哪裡
進度只存在你這台裝置的瀏覽器裡，不會上傳到任何伺服器。換手機、用無痕視窗或清除瀏覽資料，會從頭開始。

## 加到手機主畫面
- iPhone：用 Safari 打開 → 分享 → 加入主畫面
- Android：用 Chrome 打開 → ⋮ → 加到主畫面

## 注意
課程中的溫度、時間等數值以 Lycon 原廠協議為例；實際使用的蠟品若有不同規定，以該蠟品說明書為準。督導實作與術科評分需要講師，這個版本不會記錄。
